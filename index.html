Manual del Truco Compañero

¿Cómo se juega? (Las 3 banderas)

Se reparten 3 cartas a cada uno. El partido consta de manos divididas en 3 rondas. El que gana 2 de esas 3 rondas, se lleva el Truco.

El Envido (La Justicia Social)

Si tenés dos cartas del mismo palo, se suman sus valores más 20 puntos. Las figuras valen cero para sumarse entre sí, pero mantienen los 20 de base.
